# 📝 Task 06: Managing Grades in `grades.txt`

## 📌 Problem Statement
Build a C++ program that manages grades stored in **`grades.txt`**:
1. Create the file and write five integer grades.
2. Read and print the grades using a correct reading loop.
3. Ask the user for a grade to delete, then create a temporary file without it.
4. Replace the original file and show a success or error message.

---

## 📥 Input Details
The program prompts the user for the following inputs:
- **Five Integer Grades:** (e.g., `85`, `90`, `78`, `92`, `88`)
- **Grade to Delete:** (e.g., `78`)

---

**Before Deletion (`grades.txt`):**
```text
85
90
