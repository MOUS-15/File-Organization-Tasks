
# 📝 Task 01: Student Data File Operations

## 📌 Problem Statement
Write a program that accepts the student’s data (Full name, ID, Grade), then create a new text file named **“Student”** and write the student’s data on it.

---

## 📥 Input Details
The program prompts the user for the following inputs:
- **Full Name:** (e.g., John Doe)
- **ID:** (e.g., 20261010)
- **Grade:** (e.g., A+ / 95%)

---

## 📤 Output File Structure
The program creates a text file named `Student.txt` containing:

```text
Full Name: John Doe
ID: 20261010
Grade: A+
