# 📝 Task 04: Persons File Operations & Age Analysis

## 📌 Problem Statement
1. Let the user enter how many persons they want to add to the file, then enter each person's details (**name** as a `string`, **age** as an `integer`) and save them in a file.
2. Use the file saved in step 1 to load all persons' data into a `vector` of persons, find the **youngest** and **oldest** persons, and save them in a separate results file.

---

## 📥 Input Details
The program prompts the user for the following inputs:
- **Number of Persons:** (e.g., `3`)
- **Name:** `string` (e.g., `Ahmed`)
- **Age:** `integer` (e.g., `22`)
